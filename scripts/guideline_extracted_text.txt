Tentang
Dokumentasi ini merupakan panduan penggunaan UI Kit Modular untuk pengembangan antarmuka game edukasi anak. Panduan ini bertujuan untuk memastikan konsistensi visual dan fungsionalitas komponen, baik pada tahap desain di Figma maupun saat diimplementasikan ke dalam game engine (Unity).

Enabled:
{` Kondisi normal saat tombol siap untuk ditekan. Menggunakan warna dasar yang cerah dan saturasi tinggi untuk menarik perhatian pemain.`}
{`Hover/Pressed: `}
{`Kondisi saat kursor berada di atas tombol, atau saat tombol sedang ditekan. Menggunakan turunan warna yang lebih gelap (darker shade) dari warna dasar. Pada Bubble Button, state ini memberikan ilusi bahwa tombol sedang "ditekan masuk" ke dalam.`}
{`Disabled: `}
Kondisi saat aksi atau fitur pada tombol tidak tersedia/terkunci. Selalu direpresentasikan dengan warna Abu-abu (Grey). Tombol tidak akan merespon interaksi dari pemain.
{`Gaya 3D (highlight & shadow) yang playful dan meniru objek fisik. Memberikan affordance yang kuat. Cocok untuk gameplay utama.`}
Gaya minimalis, clean, dan modern. Cocok untuk menu sekunder, settings, atau UI yang lebih padat.
Penggunaan warna pada UI Kit ini tidak sekadar untuk estetika, tetapi memiliki arti fungsional (semantik) untuk membimbing pemain anak-anak dalam mengambil keputusan:
Aksi Positif / Melanjutkan.
Gunakan untuk tombol Play, Yes, Confirm, Submit, atau Next.
Aksi Netral / Navigasi.
Gunakan untuk membuka menu, Settings, Profile, Home, Store, atau Pause.
Aksi Negatif / Berhenti.
Gunakan untuk tombol Close, Cancel, No, Stop, atau Quit.
Status Nonaktif.
Eksklusif hanya untuk tombol dengan state Disabled.
Tidak ada ketentuan font khusus terkait penggunaan font, namun penulis menyarankan untuk menggunakan font “Anja Eliane”. Font ini dipilih karena bentuknya yang rounded dan tebal, sangat mudah dibaca oleh anak-anak dan selaras dengan estetika game edukasi.

Panduan ini juga dapat menjadi acuan bagi desainer maupun developer dalam mengembangkan antarmuka game secara lebih efisien.
